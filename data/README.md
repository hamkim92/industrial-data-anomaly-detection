# Data

This project uses the SECOM dataset from the UCI Machine Learning Repository.

## Dataset

- Dataset name: SECOM
- Source: UCI Machine Learning Repository
- Domain: Semiconductor manufacturing process
- Task: Pass/fail classification and anomaly detection
- Instances: 1,567
- Features: 591
- Missing values: Yes
- Label definition:
  - `-1`: Pass
  - `1`: Fail

## Data Policy

Raw datasets are not included in this repository.

This repository will document how to download and use the dataset, but the original data files should be obtained from the official UCI Machine Learning Repository.

No proprietary or confidential company data is included.

## Citation

McCann, M. & Johnston, A. (2008). SECOM [Dataset]. UCI Machine Learning Repository.
